# Privacy

Atrapo runs on your computer. There is no Atrapo server and no account.

- **Your links and files** are never sent to Atrapo. The app talks directly to the sites you paste links from (for example YouTube, Spotify, Pinterest) from your own internet connection, and saves files to your own disk.
- **Update check:** when it starts, the app requests `https://atrapo.vercel.app/version.json` to know whether a newer version exists. That request carries no personal data beyond what any web request carries (your IP address, seen by the web host).
- **Settings and history** (download folder, language, list of recent downloads) are stored in a local file in your user profile and never leave your computer. You can delete it at any time.
- **Spotify keys:** the app includes keys of an application registered with Spotify, used only to read public song and album information.

Download only content you have the right to use. You are responsible for what you download.
